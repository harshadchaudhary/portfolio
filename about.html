About me

From a B.Sc. IT degree to production microservices

I'm Harshad Chaudhary, a Junior .NET Backend Developer based in Mumbai, India. I graduated with a B.Sc. in Information Technology from Lord's Universal College, University of Mumbai, in 2025.

I joined Locobuzz as a backend intern in January 2026 and became a Junior .NET Developer in May. Since then my work has been squarely backend: C#, .NET Core and ASP.NET Core services, REST APIs and event-driven microservices talking to each other over Kafka, with SQL Server behind them, Redis in front of the hot reads and OpenSearch handling search.

The biggest change from college projects is scale and consequence. Code runs on Kubernetes against live data, so a slow query or a mishandled Kafka message is something a customer notices. That pushed me into the parts of engineering I now enjoy most — reading logs, tracing a problem across service boundaries to its real cause, and making a fix I can actually prove worked.

Before this I spent a lot of time on Python and machine learning — predictive models, Flask APIs and Streamlit dashboards. I don't work in that stack day to day now, but it's where I learned to handle data properly, and those projects are still up on my GitHub.

What I'm looking for

Backend roles where I can keep going deeper into distributed systems and .NET — more ownership of services, more design input, and a team that takes production reliability seriously.
