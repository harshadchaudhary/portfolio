Experience

Ten months writing production backend code

I joined Locobuzz as an intern in January 2026 and moved into a full-time backend engineering role in May. Locobuzz is a social listening and customer-experience platform, so the backend is a fleet of microservices ingesting a constant stream of data, enriching it and serving it back through APIs. That meant learning distributed systems on a live system rather than in a tutorial — and working in whichever language the service was written in: C#, Python or Java.
