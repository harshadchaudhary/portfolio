⚙️ Order Events — ASP.NET Core + Kafka + Redis

An event-driven backend in C# / .NET 9, built the same way the services I work on are: a REST API persists an order and publishes OrderPlaced to Kafka, and a separate worker consumes it, applies the rules and writes the outcome back. Offsets are committed manually after the handler succeeds, writes are idempotent against Kafka redelivery, and a Redis outage degrades latency rather than availability. Runs end to end with one docker compose up.
